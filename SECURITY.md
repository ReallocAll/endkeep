# Security policy

Do not disclose exploitable data-loss, path traversal, privilege bypass or world-data
exposure vulnerabilities in a public issue before maintainers can assess them.

Report privately via [GitHub private vulnerability reporting](https://github.com/ReallocAll/endkeep/security/advisories/new)
when enabled, or contact the maintainer using the
[ReallocAll GitHub profile](https://github.com/ReallocAll).

Provide the affected version, operating system, minimal reproduction and potential
impact. Redact player information, credentials and private world contents.
As a community project, EndKeep does not currently provide a guaranteed response SLA.
